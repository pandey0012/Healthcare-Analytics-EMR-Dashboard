# 🏥 Healthcare Analytics Dashboard

## 1. Project Title / Headline

**Healthcare Analytics Dashboard**

An interactive Power BI dashboard developed to analyze Electronic Medical Record (EMR) data and provide insights into patient demographics, hospital operations, doctor workload, treatment costs, payment status, and follow-up trends.

---

## 2. Short Description / Purpose

The Healthcare Analytics Dashboard is an interactive Power BI report designed to help healthcare organizations monitor hospital performance through Electronic Medical Record (EMR) data. It provides actionable insights into patient demographics, doctor workload, treatment costs, payment status, and follow-up trends, enabling faster and data-driven decision-making.

---

## 3. Tech Stack

The dashboard was built using the following tools and technologies:

- 📊 **Power BI Desktop** – Main data visualization platform used for dashboard development.
- 📂 **Power Query** – Used for data cleaning, transformation, and preparation.
- 🧠 **DAX (Data Analysis Expressions)** – Used for creating calculated measures, KPIs, and dynamic reports.
- 🔗 **Data Modeling** – Established relationships between multiple healthcare tables.
- 📈 **Interactive Visualizations** – KPI Cards, Bar Charts, Pie Charts, Line Charts, and Slicers.
- 📁 **File Format** – `.pbix` for development and `.png` for dashboard preview.

---

## 4. Data Source

**Source:** Electronic Medical Record (EMR) Dataset

The dataset contains over **10,000 healthcare records**, including:

- Patient Details
- Doctor Information
- Department Details
- Visit History
- Diagnosed Conditions
- Laboratory Test Results
- Treatment Information
- Payment Status
- Follow-up Records

The data was cleaned, transformed, and modeled using Power Query before creating the dashboard.

---

## 5. Features / Highlights

### • Business Problem

Healthcare organizations generate large volumes of patient data daily, making it difficult to monitor hospital performance and identify meaningful trends. Questions such as:

- Which departments receive the highest number of patient visits?
- Which doctors manage the highest workload?
- What is the average treatment cost?
- How many patients require follow-up?
- Which medical conditions are diagnosed most frequently?

are difficult to answer using raw healthcare data.

### • Goal of the Dashboard

The dashboard was developed to:

- Monitor key healthcare KPIs.
- Analyze patient demographics and hospital performance.
- Track doctor workload and department-wise visits.
- Evaluate treatment costs and payment status.
- Support data-driven decision-making.

### • Walkthrough of Key Visuals

#### 📌 Key KPIs

- Total Patients
- Total Visits
- Average Age
- Total Doctors
- Total Lab Tests
- Average Treatment Cost
- Follow-up Rate

#### 👥 Gender Distribution

Displays the distribution of patients across different genders.

#### 🏥 Department-wise Visits

Shows patient visits across hospital departments to identify high-demand specialties.

#### 👨‍⚕️ Doctor Workload

Ranks doctors based on the number of patient visits handled.

#### 📈 Visit Trend Over Time

Analyzes monthly patient visit trends and patterns.

#### 💳 Payment Status

Displays the distribution of Paid, Pending, and Partially Paid transactions.

#### 💊 Treatment Cost Analysis

Compares average treatment costs across different treatment types.

#### 🩺 Top Diagnosed Conditions

Highlights the most frequently diagnosed medical conditions.

#### 🎛 Interactive Filters

Users can filter the dashboard using:

- Gender
- Department
- Visit Type
- Treatment Name

### • Business Impact & Insights

- Identified departments with the highest patient volume.
- Monitored doctor workload for better resource allocation.
- Tracked treatment costs and payment status for financial analysis.
- Improved visibility into follow-up cases and patient care trends.
- Enabled faster and more informed decision-making through interactive analytics.
